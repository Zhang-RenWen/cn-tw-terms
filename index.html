    這是一個免費的線上簡繁轉換工具：貼上簡體中文，會轉成臺灣正體字，並把大陸用語換成台灣習慣的說法，例如視頻→影片、軟件→軟體、充電寶→行動電源。帶有評價意涵的詞（如顏值、下沉市場）和兩岸意思不同的詞（如窩心、愛人）會另外標示說明。想查單一詞彙，可以看兩岸用語對照表。

    字形轉換使用開源字典 OpenCC，在瀏覽器內完成，文字不會上傳。詞彙庫是 data/ 資料夾裡的 JSON 檔，歡迎提交 Pull Request 擴充。「一般用語」在「臺灣＋詞彙」模式會直接替換，其他模式只標示；「評價意涵」與「同字異義」永遠只標示，滑過可看備註；有多種說法的詞可以點一下，選擇其他說法或保留原文。台灣文字也可以貼進來檢查有沒有中國用語。
